🏋️ FITLOG – Fitness Tracking Application

About The Project

FITLOG is a modern fitness tracking web application designed to help users easily create and manage their daily workout routines.

It allows users to build personalized daily plans and save their favorite exercises for quick access. The app automatically calculates total workout duration and estimated calories burned to keep users informed of their progress.

Built with Next.js and Tailwind CSS, FITLOG offers a seamless, fast, and fully responsive experience across all devices. It aims to keep users motivated and focused on achieving their healthy lifestyle goals every day.

Key Features

1. Daily Workout Management
   Effortlessly add, view, and remove exercises from your daily workout plan.

2. Saved Workout Collection
   Bookmark and manage your favorite workout routines for future reference.

3. Real-Time Calorie & Duration Tracking
   Automatically calculates total workout duration and estimated calories burned based on your active plan.

4. Interactive State Notifications
   Toast notifications using "react-toastify" provide immediate visual feedback for actions like removing exercises.

5. Plans That Survive Refresh
   Today's workout plan and saved exercises are stored in the browser using "localStorage", so they remain available after refreshing the page.

6. Fully Responsive Design
   Provides a seamless user experience across mobile, tablet, and desktop screens using custom Tailwind CSS design patterns.

Installation and Setup

Follow these steps to run the project locally.

1. Clone the repository

git clone https://github.com/nishattasnimtonni5-lang/b-14-A-06

2. Navigate to the project directory

cd fitlog

3. Install dependencies

npm install

4. Run the development server

npm run dev

5. Open your browser

Visit http://localhost:3000 to view the website.
